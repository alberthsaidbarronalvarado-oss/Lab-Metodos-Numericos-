# Explicacion de funcionamiento
el arbol de decision en mi app consiste deacuerdo a estadistica usando gini 
sbaer deacuerdo a la edad sus ingresos mensuales y si tiene empleo saber estadisticamente si comprara o no comprara
en la ejecucion nos dara una interfaz de una ventana donde añadiremos datos la edad, ingresos mensuales 
y si tiene empleo o no lo tiene una vez añadir por ejemplo 10 datos de diferentes edades ingresos al salir de esa ventana nos 
votara otra ventana el porcentaje de compra o no compra el porcentaje deacuerdo a la edad deacuerdo a sus ingresos y deacuerdo si tiene epleo o no
